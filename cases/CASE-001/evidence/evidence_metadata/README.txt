CASE-001 — ALL EVIDENCE IN ONE FOLDER

The package contains one evidence folder with source references and metadata.

Important:
- Public-source evidence only.
- Court/prosecution allegations must remain labelled as such.
- Representational photos are NOT case evidence.
- Video/photo entries are source references where a publisher does not provide a directly downloadable file.
- Do not add private victim information, bank-account numbers, phone numbers, addresses, or leaked personal data.
